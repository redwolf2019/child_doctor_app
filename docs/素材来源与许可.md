## 占位素材（Agent 生成）

以下素材由开发 Agent 在本机用脚本程序生成，不包含来自网络的图片、动画或音频内容，随仓库按项目自有代码许可分发。

| 文件 | 生成方式 | 规格核对 | 状态 |
| --- | --- | --- | --- |
| `assets/images/exam_room.webp` | 本机插画生成后缩到 1920 × 1080 WebP | 1920 × 1080、sRGB、无按钮和文字；卡通小孩略偏左 | 占位 |
| `assets/lottie/scan_ready.webp` | 与检查室静图同一全景 | 1920 × 1080、sRGB、无文字 | 占位 |
| `assets/lottie/scan_mid.webp` | 同一角色，半透明肚子和肠道 | 1920 × 1080、sRGB、无文字 | 占位 |
| `assets/lottie/scan_closeup.webp` | 肚子近景，两只圆钝卡通虫子，右侧留空 | 1920 × 1080、sRGB、无文字 | 占位 |
| `assets/lottie/scan.json` | 三张包内 WebP 交叉淡化 + 矢量扫描线，无文字、无远程 URL | 1920 × 1080、30 fps、360 帧 = 12.0 s | 占位 |
| `assets/audio/scan_loop.mp3` | ffmpeg `aevalsrc` 正弦合成（90 Hz + 135 Hz 调制，整数周期无缝循环） | 单声道、44.1 kHz、112 kbps、4.0 s | 占位 |
| `assets/audio/worm_cue.mp3` | ffmpeg `aevalsrc` 正弦扫频合成 | 单声道、44.1 kHz、112 kbps、0.8 s | 占位 |
| `assets/audio/wash_hint.mp3` | ffmpeg `aevalsrc` 双音提示音合成 | 单声道、44.1 kHz、112 kbps、1.6 s | 占位，`[待替换]` |
| `assets/icon/app_icon_1024.png` | Python + PIL 程序化绘制 | 1024 × 1024、sRGB、无细小文字 | 占位 |
| `android/app/src/main/res/mipmap-*/ic_launcher.png` | 由 `app_icon_1024.png` 按密度缩小生成 | 48/72/96/144/192 px | 占位 |

生成脚本未提交仓库（`/tmp` 下一次性脚本），参数和分镜已记录在[产品及技术设计文档](产品及技术设计文档.md)第 7 节与占位 Lottie 脚本头注释。
